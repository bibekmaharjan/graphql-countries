# GraphQL Countries Data Visualization

A Next.js application that fetches and visualizes country, continent, and language data using the [Countries GraphQL API](https://countries.trevorblades.com/graphql). This project features interactive charts and detailed country information with dynamic continent-based filtering.

## 🚀 Features

- Interactive data visualization using Recharts
- Dynamic continent-based filtering
- Detailed country information display
- TypeScript integration for enhanced type safety
- Apollo Client for efficient GraphQL data fetching

## 📋 Prerequisites

- Node.js 18.x or higher
- npm 10.x or higher

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/bibekmaharjan/graphql-countries.git
   cd graphql-countries
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🛠️ Available Scripts

- `npm run dev` - Start development server with Turbo
- `npm run build` - Create production build
- `npm run start` - Start production server
- `npm run lint` - Run ESLint
- `npm run lint:fix` - Fix ESLint issues
- `npm run typecheck` - Run TypeScript type checking
- `npm run format:write` - Format code with Prettier
- `npm run format:check` - Check code formatting
